四层板学习记录

本文是个人学习笔记，只适合作为参考，不适合学习

什么时候需要四层板

  • 需要做阻抗匹配
  • 画不下
  • 对信号和电源要求苛刻

什么是阻抗匹配：大白话讲

信号就好像车，信号线就好像公路，如果公路一开始很宽，后面特别窄而车特别快，那么一百辆车最后过去的可能也就几辆

这就是阻抗不匹配，高速信号损失特别多。

信号做阻抗匹配时需要完整的地平面，如果地平面不完整，阻抗匹配会比较难做。

两层板不好做阻抗匹配，要把信号线做得很粗（ 几十 mil ），四层板就可以做的比较细

有些板子，比如无刷电机，对阻抗匹配、信号和电源几乎没要求，但就是要做得很小（ 对尺寸有要求 ），此时画不下，也得用四层板

对电源和信号要求严格 ==>
双层板画电源时、有的时候要打过孔然后绕到底层去布线，或者说拐个弯走线，这样子实际上不利于电源完整性，地平面会被切割来切割去的，如果对电源和信号有要求，那就要上四层板了

基础知识

层叠结构

四层板，就是四个层的板子：

（高速）信号层 -> GND 层 -> 电源层 -> （低速）信号层

（ Markdown 有点难表示立体效果，将就看吧 ）

我们之前提到信号做阻抗匹配需要完整地平面，因此距地平面近的就可以做高速信号，很方便地去做阻抗匹配。

而一般两层板则是两层不严格分离，既是电源又是地，同时也是信号。

这也就导致了如果元器件布局十分密集，那么信号线可能就要到处打过孔，因此在比较严苛的场景下可能会导致信号传输质量的问题，而如果有多层（ 四层 ），那么会非常方便 —— 我只要把电源直接打穿孔打到供电引脚就行了，可以省下很多空间在信号层给信号线布线。（ 视频有画图解释，这里受限于表述方法只能文字 ）

电源和地平面问题

原本是直接画电源线，地线，然后打比较粗的过孔

现在直接对着要供电的区域，设置一下网络然后铺铜，接下来把 PWR 层打个比较粗一点的过孔穿上来。

地平面的完整性，二层板部分信号线要割裂地平面，导致信号和电源回流路径增大，所以在信号线周围打一堆过孔，让信号 / 电源 沿着最近的过孔回流回去。

四层板不会割裂地平面，就不太需要关心这个问题，也不用说打一堆为了减小回流路径的过孔。

  2. 整洁
